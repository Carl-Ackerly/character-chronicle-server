# Private device access

The account server remains bound to 127.0.0.1:3002. Tailscale Serve supplies HTTPS privately within the owner's tailnet; Funnel must remain disabled. The ignored private-admin/private-access.json configures one exact HTTPS .ts.net origin. Arbitrary Host, Origin and forwarding headers do not grant access. HTTPS sessions use Secure, HttpOnly, SameSite=Strict cookies. Loopback HTTP remains available for local development.

After enabling Serve through the Tailscale approval page, run tailscale serve --bg http://127.0.0.1:3002. Open the resulting HTTPS address on both devices with Tailscale connected. App credentials are separate from Tailscale credentials. The PC and account server must remain running and awake for synchronization.

Before transferring an existing character, export its latest original browser copy and back up the destination database. Merge only the intended character, preserving existing account characters and all nested spellbook, notes and resource fields. Do not test using a real character. The original browser copy must remain intact.

Private HTTPS page access, owner iPhone sign-in, and automatic account-book loading were confirmed on October 18, 2026. The confirmed existing character was merged after pre-import backup; its complete record matched the source and unrelated data remained unchanged. This installation remains private, and public deployment review is pending.
